# Cold Fusion

A parametric CAD software meant to provide a free and open-source alternative
to Fusion360.

## Setting up a development environment

1. Install the latest version of [Rust](https://rust-lang.org/tools/install)
2. Clone this repository with
  `git clone git@github.com:Amenhotep314/coldfusion.git`
3. Install dependencies and compile using `cargo build`
